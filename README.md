# Trends.holic portfolio website

## Files
- `index.html` — page content and contact links
- `style.css` — responsive design for phones, tablets, laptops and desktops
- `script.js` — mobile navigation, reveal animations and current year

## Before publishing
1. Open `index.html` in a code editor.
2. Find `910000000000` in the WhatsApp link and replace it with your WhatsApp number including country code, digits only. Example format: `919876543210`.
3. Replace `hello@example.com` with your business email in both the `mailto:` link and visible text.
4. Replace the sample project concepts with your real work before calling them client projects.
5. Update the title, description, service text and brand name if needed.

## Preview on your phone
Use a mobile code editor such as Acode. Put all three files in the same folder, then open `index.html` in its preview/browser. Internet is needed for the Google Fonts import; the page otherwise uses standard HTML, CSS and JavaScript.

## Free publishing with GitHub Pages
1. Sign in to GitHub and create a new public repository, for example `trendsholic-portfolio`.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open the repository's **Settings → Pages**.
4. Under build/deployment, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. Wait for the deployment to finish; GitHub will show your live website URL in the Pages section.

Alternative: Netlify Drop can publish a folder of static website files, subject to its current account and upload requirements.

## Important
This is a static portfolio. A real online store, login system, database, or working payment checkout needs additional services and security setup.
